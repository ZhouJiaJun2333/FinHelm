# FinanceBench：美股财报问答

知识库 financebench：美股上市公司公开披露的文件，368 份 PDF，大多是 10-K（年报），也有 10-Q（季报）、8-K、
财报电话会（EARNINGS）、年度报告。文档名是「公司_期间_类型」，比如 `3M_2018_10K`、`3M_2023Q2_10Q`、`AMD_2022Q4_EARNINGS`。

- 问的是哪家公司、哪个期间，先用 `list_docs` 找到那份文档，只在那份里搜。问 FY2018 就找 2018 的 10-K；
  问某个季度（Q2 of FY2023）找那个季度的 10-Q。
- 数字以文档里的原始报表为准（合并利润表、资产负债表、现金流量表），注意单位（千 / 百万）和正负号（报表里括号是负数）。
- 题目要求按某张报表回答的，就用那张表里的数。
- 回答用问题的语言；数字写清单位。
